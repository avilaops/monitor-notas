# Monitor de Notas

- Objetivo: monitor completo com painel e API independentes, clonado do Lojas.
- Preservar a implementação original do Lojas. Não mudar seus imports ou banco.
- Builds, testes e scripts de aplicação exclusivamente no GitHub CI.
- Não executar código de aplicação em applications nem editar produção.
- Nunca copiar certificados, credenciais, dados fiscais ou arquivos .env reais.
- Não ativar coleta, manifestação ou agendadores em produção durante desenvolvimento.
- Uma fonte de coleta por CNPJ; ERP e TMS preservam suas responsabilidades.
- Contratos, proveniência e etapas em docs/PLANO.md e docs/ARQUITETURA.md.
